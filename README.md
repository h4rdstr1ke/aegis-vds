# AegisVDS (Щит для VDS)

**AegisVDS** — консольный помощник на Go для автоматического аудита VDS, проверки блокировок (ТСПУ / DPI), подбора маскировки SNI и развертывания антицензурного прокси **VLESS + Reality (XTLS-Vision)** на базе Sing-box в один клик.

## 🚀 Возможности

1. **Pre-flight аудит сервера (SSH):**
   - Проверка дистрибутива (Ubuntu, Debian, AlmaLinux и др.), ядра и архитектуры.
   - Определение типа виртуализации (KVM, OpenVZ, LXC).
   - Проверка доступности виртуального сетевого адаптера `TUN / TAP`.
   - Проверка и автоматическая активация алгоритма контроля перегрузок **TCP BBR**.
   - Определение геолокации, провайдера (ISP) и автономной системы (ASN) сервера.

2. **DPI & Censorship Diagnostics (Проверка фильтрации):**
   - **UDP Filtering Check:** определение, не блокирует и не троттлит ли локальный провайдер UDP-пакеты.
   - **Reality SNI Scanner:** живой тест пула доменов-кандидатов (Google, Apple, Cloudflare, Microsoft, Mozilla) с проверкой поддержки **TLS 1.3**, **HTTP/2 (ALPN)**, отсутствия блокировки со стороны локального провайдера и минимальной задержки (RTT).
   - **Матрица совместимости протоколов:** автоматический вердикт по протоколам (VLESS Reality, Hysteria 2, AmneziaWG, Shadowsocks-2022, WireGuard, OpenVPN).

3. **Zero-Touch Deployer (Развертывание в 1 клик):**
   - Автоматическая установка легковесного ядра **Sing-box** на VDS.
   - Криптографическая генерация ключевой пары **X25519**, Short ID и UUID пользователя.
   - Создание конфигурации `/etc/sing-box/config.json` и systemd-сервиса с автозапуском.
   - Настройка файрвола (UFW / iptables) для порта 443.

4. **Экспорт и подключение:**
   - Готовая ссылка стандарта `vless://...`.
   - **ANSI QR-код прямо в терминале** для мгновенного сканирования камерой смартфона.
   - Готовый клиентский JSON-конфиг (`aegis-client-config.json`) для десктопных клиентов.

## 🖥 Нативное десктопное приложение (Desktop App)

AegisVDS теперь работает как **полноценное оконное приложение Linux** (GTK3 / Wayland / X11) с собственной иконкой в панели задач, независимым окном и ярлыком в меню приложений системы:

### 1. Запуск из меню приложений (OS App Launcher)
Нажмите клавишу **Super / Win** на клавиатуре, введите в поиске **`AegisVDS`** и кликните на иконку щита. Приложение запустится в своем отдельном окне.

### 2. Запуск из терминала
```bash
cd ~/Projects/aegis-vds

# Запуск десктопного оконного приложения:
./aegis-desktop
# или
./aegis
```

## 🛠 Консольный режим (CLI)
Если вы запускаете утилиту на удаленном сервере без графической оболочки:
```bash
# Интерактивный CLI-мастер в терминале:
./aegis cli

# Экспресс-диагностика VDS:
./aegis probe -h 198.51.100.1 -u root

# Сканирование доменов маскировки Reality SNI:
./aegis scan-sni
```

## 📁 Структура проекта

- `cmd/aegis/main.go` — точка входа CLI, мастер и команды.
- `internal/ui/` — терминальный UI, баннеры, цветовая схема ANSI, форматирование.
- `internal/sshclient/` — SSH-клиент для удаленного управления сервером.
- `internal/probe/` — модули аудита:
  - `system.go` — сбор параметров VDS (ОС, BBR, TUN, RAM).
  - `network.go` — GeoIP, ASN, замеры задержки и джиттера.
  - `sni_checker.go` — сканер TLS 1.3 / HTTP/2 маскировочных доменов для Reality.
  - `dpi.go` — тест UDP и оценка протоколов против ТСПУ.
- `internal/crypto/` — генератор ключей X25519 (ECDH Curve25519), Short ID и UUID.
- `internal/deployer/` — автоустановка Sing-box, включение BBR, генерация конфигураций и systemd.
- `internal/exporter/` — генерация ссылок `vless://`, ANSI QR-кода в консоли и клиентского JSON.
